# yt-ads-studio-dist

Repo distribusi (publik) YT ADS STUDIO.

- File rilis: installer NSIS wizard `YT-ADS-STUDIO-Setup-<ver>.exe` + `latest.yml` (metadata auto-update electron-updater).
- App memeriksa repo ini via electron-updater (badge “Periksa Pembaruan” di pojok kanan atas).
- Versi mengikuti semver di `package.json` app; rilis ditandai `v<ver>`.

> Source code private di repo terpisah.
